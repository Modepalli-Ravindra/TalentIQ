# 09 UI/UX Guidelines

## Design Principles
1. **Frictionless Efficiency**: Achieve key tasks in < 3 clicks.
2. **Predictable Feedback**: Optimistic UI updates with instant loading skeletons and clear toast notifications.
3. **Glassmorphism & Depth**: Subtle background blurs, ambient gradient spotlights, floating cards, and translucent borders (`#27272A`).
4. **Keyboard-First Design**: Global command palette (`Cmd + K`) for instant navigation and action execution.

---

## Accessibility Standards
- Contrast ratio >= 4.5:1 on dark backgrounds.
- Explicit keyboard focus rings with electric blue glow.
- Complete ARIA labels on dynamic components (Kanban board, charts, modals).
