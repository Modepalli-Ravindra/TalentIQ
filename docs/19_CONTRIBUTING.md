# 19 Contributing Guidelines

We welcome contributions to TalentIQ AI! Please adhere to the following workflow:

1. **Fork & Branch**: Create a feature branch (`git checkout -b feature/amazing-feature`).
2. **Coding Standards**: Ensure code conforms to ESLint, Prettier, and Python `black` formatting.
3. **Commit Messages**: Follow Conventional Commits convention (`feat: add resume match meter component`).
4. **Pull Request**: Submit PR referencing relevant issue number with test verification details.
